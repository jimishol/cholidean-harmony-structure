# **Umbilic‑Surface Harmony Grammar**

## 🎼 **1. Surfaces**

A **surface (S)** is a node on the **circle of fourths**:

`C → F → Bb → Eb → Ab → Db → Gb → B → E → A → D → G → C`

Each surface is a **4-note Major7 set** generated by a specific Tonic (**T**). The surface contains the notes: **{T, 3rd, 5th, 7th}**.

All harmonic objects (single tones, dyads, triads) are derived strictly from these four notes.

---

### **1.1 Surface Objects**

The following objects can be read from a surface:

1.  **Single Pitch:**
    *   `T`: The Generator/Root of the surface.

2.  **Dyads (Local Intervals):**
    *   Defined by their structural role within the Major7 set.
    *   *Note: Diagonals are non-directional; labels are local to the surface.*

    | Dyad | Strict Definition | Description |
    | :--- | :--- | :--- |
    | **c** | `{T, 5th}` | **Curve** (Perfect 5th) |
    | **e** | `{T, 3rd}` | **Edge** (The Augmented-Triad link) |
    | **d** | `{3rd, 5th}` | **Diagonal** (The internal minor 3rd) |
    | **l** | `{7th, T}` | **Leading** (Major 7th interval) |

3.  **Triads:**
    *   `M` = **Major Triad** on `T` `{T, 3rd, 5th}`.
    *   `m` = **Minor Triad** on the remaining notes `{3rd, 5th, 7th}`.
    *   *Border-spanning triads (e.g., `l0e`) appear as cohered sequences.*

4.  **Emergent Major7 Chords:**
    *   `m0M` or `M0m` (Cohered sequences).
    *   The order `m0M` points to the canonical chord name (e.g., on C-Surface: `m`[Em] + `M`[C] = Cmaj7).

> **Note:** Objects (`T, c, d, e, l, m, M`) belong strictly to their surface. Border edges (`e`) interact across surfaces only during triangle rotations or pivots.

---

### **1.2 Surface Topology**

While a surface is a distinct logical unit, its components interact with the larger lattice:

*   **Unique Identity:** The surface is named by its single **T-note** (The Generator).
*   **Shared Vertices:** The remaining three notes (3rd, 5th, 7th) are topologically shared; they function as **T-notes** or structural points on adjacent surfaces.
*   **Internal vs. Border Geometry:**
    *   **d** (Diagonal) and **l** (Leading): These are **purely internal diagonals**. They exist strictly *inside* the surface geometry.
    *   **c** (Curve) and **e** (Edge): These form the **structural borders** of the surface.

> **Summary:** The surface is **self-contained in definition** (it owns its objects), but **interconnected in structure** (it shares its borders).

> **1.3 Notation Convention**
> To distinguish the **Surface** (the container) from a specific **Pitch** (a note), we use the prime symbol (`'`).
> *   **C** refers to the note C.
> *   **C'** refers to the **C-Surface** (containing {C, E, G, B}).
---

## 🔺 **2. Directed Augmented-Triad Triangles**

Four directed 3-cycles define surface connections:

1. **C → Ab → E → C**
2. **F → Db → A → F**
3. **D → Bb → Gb → D**
4. **G → Eb → B → G**

Each directed edge belongs to exactly **one surface** — the surface at the **end** of the arrow.

These cycles represent **rotation** around the circle of fourths, where each **triangle rotation** (P or S) spans edges between surfaces.

---

## 🔢 **3. Movement Tokens**

Movement tokens represent shifts and rotations between surfaces. Each token is a pair (s, r), where:

* **s**: **Station shift** modulo 4, where **s ∈ {0, 1, 2, 3}**
* **r**: **Triangle rotation** modulo 3, where **r ∈ {0, 1, 2}**

### **Decomposition of Movement Token**

Given an integer **n** ∈ ℤ:

n = k * 4 + (n mod 4)

Where:

* **k = ⌊n / 4⌋**: Quotient (full cycles of 4)
* **n mod 4**: Remainder — **station shift** (**s**)
* **r = k mod 3**: Rotation based on the quotient **k**

Thus, the movement token (s, r) is defined as:

(s, r) = (n mod 4, ⌊n / 4⌋ mod 3)

### **Example:**

For **n = 8**:

* 8 = 2 * 4 + 0
* **k = 2**, **s = 0**, **r = 2 mod 3 = 2**
* Movement token: (s, r) = (0, 2)

---

### **Summary:**

* **Station shift (s)**: s = n mod 4 — Movement across surfaces.
* **Rotation (r)**: r = ⌊n / 4⌋ mod 3 — Rotation within a surface.
* Movement tokens (s, r) encapsulate both surface shift and triangle rotation.

---

## 🔁 **4. Rotation Shorthand**

* **S = 1**: First triangle rotation
* **P = 2**: Second triangle rotation
* **0**: No rotation (identity) — omitted by default

Numeric labels **0, 1, 2** remain canonical for triangle rotation.
*(Station shifts are defined in Section 3. Default **1 shift** and **0 rotation** are omitted, so **SX** is shorthand for **1SX** and **X** is shorthand for **1 0 X** when no number is specified.)*

---

## **5. Movement‑Indexed Objects**

Every explicit token is a triple:

**{s} {r} {o}** with:

* **s ∈ {0,1,2,3}** — surface‑step (station shift)
* **r ∈ {0, S, P}** — triangle‑motion (0, 1, 2)
* **o ∈ {M, m, c, e, d, l, T}** — local object read *at* the destination surface

**Movement (s, r)** together determines the destination surface (equivalently, `n mod 12` with `n -> (s = n mod 4, r = (n // 4) mod 3)`). The **surface itself** (its 4‑note Major7 set) is implicit and never encoded separately.

### **Core Identity Rules**

* **M** = the major triad built on the surface’s **T** (T–a–b).
* **m** = the other minor triad contained in the same Major7 (the three **non‑T** notes a–b–c).
* **c, e, d, l, T** are the surface‑relative dyads and the single naming note as in the summary.

### **Default Expansion and Notation**

* **Default‑expansion**: A bare local object token `X` is shorthand for `1 0 X`. Notationally:
  **X ≡ 1 0 X.**
  To read on the current surface, write **0X**.

* **Shorthand**: **S = 1**, **P = 2** for triangle‑motion; numeric 0,1,2 remain canonical.

* **“=”** remains a human commentary anchor only; it does not change formal evaluation.

### **Evaluation Order and Canonical Bookkeeping**

1. **Expand omitted defaults** to explicit ((s, r)).
2. **Apply station shift s first**, then triangle rotation r; the resulting surface is where the local object o is read.
3. **Canonical sums:** To compute net movement, sum all **s mod 4** and **r mod 3**, where the sum of all **s mod 4** follows the previous algorithm, and **r mod 3** is determined by the quotient of ( n \div 4 ), reduced modulo 3.
4. **Parenthesized tokens** are sounded as remainders/anchors.

### **Minimal Examples**

* **Read current‑surface major triad:** `0M` → Major triad on the current surface.
* **Default move then triad:** `M` ≡ `1 0 M` → Move one station, then read M.
* **Mm from G (compact):** Starting on G, `Mm` → Expand to `1 0 M` then `1 0 m` → G→C read **C major**, then C→F read **m on F** = **A–C–E** (A minor). Final object = **ACEG**

---

**Concise Rule to Paste:**

“Omitted movement expands to `1 0` (`X ≡ 1 0 X`); `M` is the triad on T, `m` is the three non‑T notes of the surface’s Major7; always expand defaults, apply s then r to find the destination surface.”

---

## 🧱 **6. Cohered Subset Rule**

A contiguous sequence of tokens is parsed as one cohered subset:

* **left-to-right evaluation**
* **S/P are shorthand for r=1 and r=2; expand to numeric r during parsing.**
* **each token evaluated at the surface reached by the previous token**
* **Triangle-motion is always applied at the surface obtained after the station shift, not at the starting surface.**
* **accumulate (s, r) as you go**

---

## 🎚️ **7. Non-Triadic 3-Tone Sets**

Represented as ordered sequences of dyad tokens from `{c, d, e, l}`.

* **order matters**: `e0l` ≠ `0el`
* **numeric prefixes allowed**

---

## **8. Anchoring and Linear Sustain**

**Definition**
Parentheses `(X)` denote a **Sustained Object**.
The token `X` is evaluated normally: it advances the running surface and selects an object. The parentheses indicate that this object **continues to sound** while the grammar processes subsequent tokens.

### **The Linear Rule**
`(X)` is part of the main movement chain. It does not create a side-branch.
*   **Sequence:** `A (B) C`
*   **Logic:**
    1.  Move to `A`.
    2.  From `A`, move to `B`. **Hold the sound of B.**
    3.  From `B`, move to `C`.

### **Example: The Pivot Bridge**
Transitioning from **Cmaj7** to **F#m7(11)** (F#-A-E-B):
`m0M > (Pc) 2d`

1.  **`m0M`**: Establish Cmaj7 on the **C-Surface**.
2.  **`(Pc)`**:
    *   Apply `P` rotation (C' $\to$ **E'**).
    *   Read `c` (E-B). **Hold this.**
    *   *System is now located at E'.*
3.  **`2d`**:
    *   Apply `s=2` shift (E' $\to$ **D'**).
    *   Read `d` (F#-A).
    *   *System is now located at D'.*

**Result:** The E-B dyad is carried over from the E-Surface to blend with the F#-A of the D-Surface.

## 9. Proposition: Naming and Equivalence

For any **cohered subset** ( X ), the **chord name** of ( X ) is the object produced by the last token of ( X ). Two token sequences produce the **same chord** (i.e., the same pitch-class set) **if and only if** they have identical canonical movement (i.e., the same (\sum s \bmod 4), (\sum r \bmod 3)) and identical final local objects after evaluation.

**Note**: The final local object is the evaluated object of the last token under the grammar's left-to-right evaluation rules.

## 10. Branching and Reconvergence Notation

**Purpose**: Defines the notation for two‑branch structures, parallel continuations, and reconvergence points.

* **Branch Start**: `A B.C`

  * **A** is the common origin.
  * **B** = left continuation, **C** = right continuation.
* **Continuation (compact form)**: `A B.C D.E F`

  * Left path: `A → B → D → ...`
  * Right path: `A → C → E → ...`
* **Reconvergence (choose one)**:

  * `leftF` — Canonical continuation follows the left branch; right becomes an alternative/provenance.
  * `rightF` — Canonical continuation follows the right branch; left becomes an alternative/provenance.
  * `leftF|rightF=Label` — Record both provenances; `=Label` is the synthesized working surface used downstream.
